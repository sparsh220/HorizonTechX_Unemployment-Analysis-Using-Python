# Unemployment Analysis Using Python

## About the Project
This project analyzes unemployment rates in different regions and studies unemployment trends before and during COVID-19 using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Project Steps
- Basic Data Understanding
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Regional unemployment analysis
- COVID-19 impact analysis
- Correlation analysis

## Key Findings
- Unemployment rates vary across regions.
- Tripura recorded the highest average unemployment rate, while Meghalaya recorded the lowest in my analysis.
- Unemployment increased significantly during the COVID-19 period.
- The graphs help identify unemployment patterns and labour participation trends.

## Conclusion
This project helps understand unemployment trends and regional differences. The findings can support further research and help policymakers plan employment opportunities.
